# Changelog

## 1.0.1

- Scrollbar sliders now use the green accent (idle, hover and drag).
- Extras CSS no longer forces a single scrollbar color, so the theme states apply.

## 1.0.0

- First public release.
- Carbon Lime color theme: workbench, syntax and semantic token colors.
- Optional UI extras (`extras/carbon-lime.css` and `extras/carbon-lime.js`) for the Custom CSS and JS Loader extension.
